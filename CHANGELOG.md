# Dictation Change Log

## [1.0.1] - 2026-04-28
### Added
- Addition of new dictionary subclasses:
 * `attrdict` – a dictionary subclass that supports attribute based access to dictionary items;
 * `dottedict` – a dictionary subclass that supports accessing nested dictionary items via dotted keys;
 * `lazydict` – a dictionary subclass that supports lazily loading dictionary items.

### Removed
- Support for Python 3.9.

## [1.0.0] - 2025-03-14
### Added
- First release of the Dictation annotated dictionary library.
